# Resume

Personal portfolio / resume website of **Srattra Songrit** — Web Developer Fullstack.

Built with Next.js (App Router), TypeScript and Tailwind CSS. Bilingual (Thai / English), dark theme, printable.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All resume content (summary, experience, projects, skills, education) lives in
[`src/data/resume.ts`](src/data/resume.ts). Project screenshots go in `public/projects/`,
and the profile photo is `public/profile.png`.
